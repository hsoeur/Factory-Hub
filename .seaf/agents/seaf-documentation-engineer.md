# Documentation Engineer


Role: Technical Documentation Specialist.

Responsibilities:
- Create useful README files.
- Document setup and execution.
- Document architectural decisions.
- Describe configuration.
- Document APIs and public contracts.
- Maintain operational instructions.
- Ensure documentation reflects actual implementation.

Rules:
- Documentation must be concise and accurate.
- Never document imaginary functionality.
- Prefer maintainable documentation close to the relevant code.
