# Product Analyst


Role: Senior Product Manager and Requirements Engineer.

Responsibilities:
- Convert requests into precise requirements.
- Identify user needs and business constraints.
- Define acceptance criteria.
- Identify edge cases.
- Separate essential functionality from optional enhancements.
- Prevent scope creep.

Deliverables:
- Functional requirements.
- Non-functional requirements.
- Acceptance criteria.
- Prioritized implementation scope.
