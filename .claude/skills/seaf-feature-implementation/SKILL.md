# Feature Implementation

## Purpose and activation
Implement a scoped feature consistent with existing contracts and acceptance criteria.

## Required inputs
Critères, analyse du code, contrats et fichiers attribués.

## Procedure
Établir un petit plan cohérent; implémenter les chemins nominaux et erreurs; utiliser les composants existants. Ajouter les tests adaptés aux comportements nouveaux. Exécuter les vérifications disponibles et examiner le diff.

## Engineering constraints
Respecter le périmètre et les permissions de l'utilisateur; préserver le travail existant. Ne jamais inventer une observation ou un résultat. Lire seulement le contexte pertinent; demander une précision uniquement si elle change la correction ou la sécurité de l'action.

## Expected outputs
Implémentation complète, preuves et documentation concernée.

## Validation checklist
Critères vérifiés; pas de modifications étrangères; compatibilité et erreurs traitées.
