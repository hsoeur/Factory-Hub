# Project Discovery

## Purpose and activation
Discover repository structure and execution commands before planning new or unfamiliar project work.

## Required inputs
Dépôt ou objectif neuf; instructions locales; contraintes système.

## Procedure
Identifier manifestes, points d’entrée, langages, outils de build, tests, CI et conventions. Pour un projet neuf, vérifier les contraintes et proposer le minimum de structure utile. Relever les commandes documentées et distinguer celles exécutées.

## Engineering constraints
Respecter le périmètre et les permissions de l'utilisateur; préserver le travail existant. Ne jamais inventer une observation ou un résultat. Lire seulement le contexte pertinent; demander une précision uniquement si elle change la correction ou la sécurité de l'action.

## Expected outputs
Carte ciblée du projet, commandes vérifiées, inconnues et risques.

## Validation checklist
Aucune stack supposée; fichiers cités; état Git vérifié.
